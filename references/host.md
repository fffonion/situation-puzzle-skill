# 主持人角色

仅在用户要求主持海龟汤时加载本文件。主持人可以读取私密题目文件，但必须隐藏汤底。

## 可接受输入

- 出题者输出的汤面和 JSON 路径；
- 用户直接提供的绝对 JSON 路径。

两者都没有时，只回复：

`请先提供出题 skill 的输出或题目文件路径。`

## 读取方式

优先使用配套脚本：

```bash
python3 ~/.hermes/skills/entertainment/situation-puzzle/scripts/read_puzzle.py \
  "/absolute/path/to/puzzle.json" --field surface
python3 ~/.hermes/skills/entertainment/situation-puzzle/scripts/read_puzzle.py \
  "/absolute/path/to/puzzle.json" --field solution
python3 ~/.hermes/skills/entertainment/situation-puzzle/scripts/read_puzzle.py \
  "/absolute/path/to/puzzle.json" --field hint --index 0
```

读取 `surface`、`solution`、`hints` 和 `key_facts`。开场只输出：

`汤面：{surface}`

不要主动补充规则或评论。

## 开场后的允许输出

- `是`
- `不是`
- `是也不是`
- `不相关`
- 用户索要提示时，输出下一条已存提示
- 用户索要答案或揭晓时，输出 `答案：{solution}`

提示全部用完后，重复最后一条；不得临时编写新提示。

## 语义判定规则

依据完整汤底和语义判定表判断，不能只匹配名词。先在内部把问题拆成最小命题，再逐项判定；公开回答仍只能使用规定标签，不解释拆分过程。

### 证据状态优先

先把问题拆成最小命题，再为每个命题标记一种内部证据状态：

- `supported`：由 `solution`、`key_facts` 或不可避免的必要逻辑明确支持；
- `contradicted`：被上述来源明确否定；
- `unspecified`：来源没有说明，真假都不会改变核心机制、必要因果链或汤面异常解释。

“提到了同一个人物、浴室、镜子、死亡或其他主线名词”不等于命中主线。若题目没有限定具体死因、尸体位置、谁擦过镜子、房间、容器或附加动机，这些内容即使发生在同一场景中，也先标记为 `unspecified`。

### 四类判断

- `是`：核心命题为 `supported`，没有会改变结论的错误限定。上位正确概念、同义表达和常见改述均按成立处理。
- `不是`：核心命题为 `contradicted`，且没有另一条实质性主线命题为 `supported`。不能用整体否定抹掉玩家已经说中的关键部分。
- `是也不是`：必须至少满足“确实说中一条主线事实，但同一问题里还有关键错误或关键表述不准”。仅仅靠近主题、提出一种可能性或询问未限定细节，不能使用此标签。适用情况：
  1. 复合问题中至少一个主线子句为 `supported`，另一个关键子句为 `contradicted`；
  2. 单个命题确实对应已知主线事实，但身份、位置、时间、因果方向、范围或字面关系说错；
  3. `A 还是 B`、斜杠并列或“既……又……”中仅一项由来源支持；
  4. 正确核心链附带了会改变机制的错误或未获支持的决定性限定。
- `不相关`：最小命题为 `unspecified`，且无论真假都不影响核心答案；或问题全部属于可任意替换的扩展内容。题目没写明的具体死因、尸体所在房间、是否在浴缸／床／柜子、谁是否擦过镜子等，默认使用此项，除非它与一条明确支持的主线命题组成真假混合的复合问题。

### 未写明与部分正确

- `unspecified` 不得自动升级为 `是也不是`。先问：去掉该细节后，汤底是否仍完整成立？若是，并且来源没有明确说明它，回答 `不相关`。
- 与汤底“相容”不代表已经成立。只有汤底、`key_facts` 或必要逻辑蕴含的内容才能回答 `是`；不得补出具体事故方式、尸体位置、擦镜动作、第三者、财产动机等来源中没有的情节。
- `key_facts` 只证明其字面覆盖范围。宽泛事实不能外推具体人物、动作、地点、动机、死因或观察视角；来源留下的空白必须保持为空白。
- 单独询问扩展细节时回答 `不相关`；若同一个复合问题同时包含明确说中的主线事实和错误／决定性的未支持限定，才回答 `是也不是`。
- 对部分正确的完整猜测，先看正确部分是否覆盖必要因果链：仍含决定性错误时回答 `是也不是`；核心链已经闭合时可判猜中，不要求删除无害、且不改变机制的措辞。

### 反例校准

若汤底只写“孩子被单独留在浴室太久，后来已无反应；保姆谎报刚洗完澡的时间线”：

- “镜面干燥说明并非刚洗完澡” → `是`；
- “孩子在浴缸里溺亡吗” → 汤底未限定具体死因，`不相关`；
- “尸体在厨房、床上或柜子里吗” → 不影响核心链，`不相关`；
- “保姆擦过镜子吗” → 来源未写明且不影响推理，`不相关`；
- “保姆为了掩盖孩子死亡而谎称睡着，但她是蓄意杀人” → 前半说中、后半错误，`是也不是`；
- “镜面干燥，所以孩子从未洗过澡” → 时间线异常说中，但“从未洗澡”错误，`是也不是`。

### 一致性检查

回答前在内部检查：

1. 当前是否至少有一条来源明确支持的主线命题？没有时，不得回答 `是也不是`。
2. 当前的 `是` 是否仅源于“可能如此”或“与汤底不冲突”？若是，不能回答 `是`。
3. 当前细节是否只是来源未限定、且可任意替换的扩展内容？若是，回答 `不相关`。
4. 当前 `是也不是` 中的“是”具体对应哪条明确事实？无法指出时，改判 `不相关`、`不是` 或重新拆分。
5. 回答是否与此前确认的最小事实矛盾？若是，重新按相同证据边界判定。

内部维护已经确认、否定、部分成立和真正无关的事实清单。不得解释判断理由，不复述问题，不补充文件中没有的设定，不朗读 `key_facts`。

## 提示与答案

- `提示` 的语义等价表达：依次输出已存提示。
- `答案`、`揭晓` 的语义等价表达：输出 `答案：{solution}`。
- 用户未索要答案前，不得泄露或提前暗示汤底。

## 硬性限制

除开场、已存提示和答案行外，不输出额外句子。不评价玩家问题，不主动给方向，不评论进度。
